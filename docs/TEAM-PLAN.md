# План для команды из 3 человек

Общий лимит: 5 часов, включая разработку, интеграцию, проверку и подготовку репозитория к сдаче.

В начале работы назначьте конкретные имена на роли A, B и C.

| Участник | Основная ответственность | Файлы |
|---|---|---|
| A: интерфейс | Каталог, конструктор, кабинеты бизнеса и студента, стили | `static/` |
| B: сервер и данные | SQLite, рейтинг, публикация, отклики, ручной выбор бизнеса | `server.py`, кроме AI-функций |
| C: AI и качество | AI-контракт, вопросы, валидация AI-ответов, тесты и документация | AI-функции в `server.py`, `tests/`, `docs/`, `README.md` |

B и C работают с разными участками `server.py`.

Границы ответственности:

**C отвечает за:**

- `AI_PROMPT`
- `QUESTIONS`
- `ai_questions`
- `validate_ai_result`

**B отвечает за:**

- SQLite;
- состояние приложения;
- рейтинг;
- создание и обновление карточек;
- публикацию;
- отклики;
- ручное решение бизнеса;
- API, не относящиеся к AI.

Перед параллельной работой необходимо договориться о границах изменений и регулярно синхронизировать Git.

# График на 5 часов

| Время | Участник A | Участник B | Участник C | Общая контрольная точка |
|---|---|---|---|---|
| 00:00–00:30 | Каркас экранов и навигация | Схема данных и API | AI-контракт и сценарий проверки | Согласованы поля карточки и статусы |
| 00:30–01:40 | Черновик, вопросы, редактор | Сохранение карточки и проверка данных | Уточняющие вопросы и проверка AI-ответов | Черновик превращается в карточку |
| 01:40–02:45 | Рейтинг и каталог | Формула, пересчёт и сортировка | Проверка уровней рейтинга и тестовых данных | Рост рейтинга влияет на позицию задачи |
| 02:45–03:45 | Форма отклика и кабинеты | Отклики и ручные решения бизнеса | Проверка полного сценария | Студент отправляет отклик, бизнес принимает решение |
| 03:45–04:30 | Исправления интерфейса | Ошибки и сохранение данных | Тесты, README и документация | Основной сценарий проходит без ошибок |
| 04:30–05:00 | Проверка интерфейса | Проверка запуска и базы | Проверка репозитория и требований | Проект готов к сдаче |
